# CS110-Week10

## Overview
**Game:** Bedwars
**Goal:** Capture beds
**Player action:** Upgrade armor, kill other players, hit bed with axe
**Feedback:** Bed weakens with each hit & gets eliminated
**Source link:** https://www.minecraft.net/en-us/marketplace/pdp/waypoint-studios/original-bed-wars/e5e0b70b-849c-4f99-a5fb-c220f788dd3e

## 3 Engines:
### 1. Unity
- 2D & 3D
- C#
- Cross-platform deployment
### 2. Unreal Engine
- 3D
- C++ & Blueprints
- Real-time rendering
### 3. Godot Engine
- 2D & 3D
- GDScript, C3, C++
- Lightweight, open-source

### Chosen one: Unity
- Robust multiplayer networking packages and its block-based rendering make it ideal for multiplayer mini game prototypes

**One game object:** sword
**Data 1.** Upgrade level (wood —> iron —> diamond —> emerald)
**Data 2.** Equipped/Unequipped
**Action:** Hits players
